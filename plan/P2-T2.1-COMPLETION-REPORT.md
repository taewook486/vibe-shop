## 작업 내용

### 1. 마이페이지 완전 재작성 (/src/app/(shop)/my/page.tsx)

#### 주요 변경 사항
- **Supabase Auth 제거**: `createClient()`, `signOut()` 등 완전 제거
- **NextAuth 통합**: `useSession()`, `signOut()` 사용
- **API 라우트 호출**: 직접 DB 조회 대신 `/api/profile/[id]` 사용

#### 변경된 import
```typescript
// Before
import { signOut } from '@/lib/supabase/auth';
import { createClient } from '@/lib/supabase/client';
import type { User as SupabaseUser } from '@supabase/supabase-js';

// After
import { useSession, signOut } from 'next-auth/react';
```

#### 핵심 로직 변경
```typescript
// Before: useEffect에서 Supabase Auth 사용
const supabase = createClient();
const { data: { user } } = await supabase.auth.getUser();

// After: NextAuth useSession 사용
const { data: session, status } = useSession();
if (status === 'authenticated' && session?.user) {
  const res = await fetch(`/api/profile/${session.user.id}`);
}
```
