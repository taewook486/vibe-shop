# User Flow (사용자 흐름도)

> Vibe Store의 핵심 사용자 여정

---

## MVP 캡슐

| # | 항목 | 내용 |
|---|------|------|
| 1 | 목표 | 라이브 코딩 콘텐츠용 쇼핑몰 스캘레톤 완성 |
| 2 | 페르소나 | 실력이 부족하지만 AI로 커스터마이징 가능한 비개발자 |
| 3 | 핵심 기능 | FEAT-1: 디지털 상품 판매 (리스트/상세/결제/다운로드) |
| 4 | 성공 지표 (노스스타) | 유튜브 구독자 수 (5천 → 1만, 3개월) |
| 5 | 입력 지표 | 라이브 시청자 수, 스캘레톤 다운로드 수 |
| 6 | Out-of-scope | 실물 배송, 코칭 예약 (Phase 2) |
| 8 | Top 리스크 | Supabase RLS 보안 정책 설정 복잡도 |
| 10 | 다음 단계 | 프로젝트 초기 세팅 (Next.js + Supabase) |

## 1. 전체 사용자 여정 (Overview)

```mermaid
graph TD
    A[스토어 진입] --> B{로그인 상태?}
    B -->|No| C[비회원으로 쇼핑]
    B -->|Yes| D[회원으로 쇼핑]
    C --> E[상품 탐색]
    D --> E
    E --> F[장바구니 담기]
    F --> G{결제 진행?}
    G -->|Yes| H[결제 플로우]
    G -->|No| E
    H --> I{결제 성공?}
    I -->|Yes| J[주문 완료]
    I -->|No| K[에러 안내]
    K --> H
    J --> L[다운로드 센터]
    L --> M{재방문?}
    M -->|Yes| E
```

## 2. FEAT-0: 온보딩/로그인 플로우

```mermaid
graph TD
    A[스토어 진입] --> B{회원가입 필요?}

    %% 비회원 주문
    B -->|아니오| C[비회원 쇼핑]
    C --> D[결제 시 이메일만 입력]
    D --> E[주문 완료]
    E --> F[비밀번호 설정 유도]
    F -->|수락| G[회원 전환]
    F -->|거부| H[비회원 유지]

    %% 소셜 로그인
    B -->|예| I[로그인 방법 선택]
    I --> J[카카오 로그인]
    I --> K[구글 로그인]
    I --> L[이메일 매직 링크]

    J --> M{인증 성공?}
    K --> M
    L --> N[이메일로 링크 전송]
    N --> O[링크 클릭]
    O --> M

    M -->|Yes| P[프로필 확인/완성]
    M -->|No| Q[에러 표시]
    Q --> I

    P --> R[스토어 메인]
```

## 3. FEAT-1: 디지털 상품 구매 플로우

### 3.1 상품 탐색

```mermaid
graph TD
    A[스토어 메인] --> B[상품 목록]
    B --> C{필터/검색?}
    C -->|Yes| D[카테고리 필터]
    C -->|Yes| E[태그 검색]
    D --> F[필터된 목록]
    E --> F
    C -->|No| F

    F --> G[상품 카드 클릭]
    G --> H[상품 상세 페이지]

    H --> I[상품 정보 확인]
    I --> J[미리보기 확인]
    J --> K{구매 결정?}
    K -->|Yes| L[장바구니 담기]
    K -->|No| B
```

### 3.2 장바구니 & 결제

```mermaid
graph TD
    A[장바구니 페이지] --> B{상품 있음?}
    B -->|No| C[빈 장바구니 안내]
    C --> D[상품 탐색 유도]

    B -->|Yes| E[상품 목록 표시]
    E --> F{수량 변경?}
    F -->|Yes| G[수량 조절]
    G --> E
    F -->|No| H{삭제?}
    H -->|Yes| I[상품 제거]
    I --> E

    H -->|No| J[결제하기 클릭]
    J --> K{로그인 상태?}
    K -->|No| L[이메일 입력]
    K -->|Yes| M[주문 정보 확인]
    L --> M

    M --> N[토스페이먼츠 결제창]
    N --> O{결제 성공?}
    O -->|Yes| P[결제 승인 API]
    O -->|No| Q[결제 실패 안내]
    Q --> M

    P --> R{승인 성공?}
    R -->|Yes| S[주문 완료 페이지]
    R -->|No| T[승인 실패 안내]
    T --> M
```

### 3.3 다운로드 센터

```mermaid
graph TD
    A[주문 완료] --> B[다운로드 센터 이동]
    B --> C[구매 상품 목록]

    C --> D[다운로드 버튼 클릭]
    D --> E{권한 확인}
    E -->|유효| F[Signed URL 생성]
    F --> G[파일 다운로드 시작]
    E -->|무효| H[권한 없음 안내]

    G --> I{다운로드 횟수 제한?}
    I -->|초과| J[제한 안내]
    I -->|OK| K[다운로드 완료]

    K --> L{재다운로드?}
    L -->|Yes| D
    L -->|No| M[마이페이지]
```

## 4. FEAT-2: 관리자 플로우

### 4.1 상품 관리

```mermaid
graph TD
    A[관리자 로그인] --> B[관리자 대시보드]
    B --> C[상품 관리]

    C --> D{작업 선택}
    D -->|등록| E[새 상품 폼]
    D -->|수정| F[상품 선택]
    D -->|삭제| G[상품 선택]

    E --> H[기본 정보 입력]
    H --> I[상품 유형 선택]
    I -->|Digital| J[파일 업로드]
    J --> K[가격/상태 설정]
    K --> L[저장]

    F --> M[상품 정보 수정]
    M --> L

    G --> N[삭제 확인]
    N -->|Yes| O[Soft Delete]
    N -->|No| C

    L --> P{성공?}
    P -->|Yes| Q[목록으로]
    P -->|No| R[에러 표시]
    R --> E
```

### 4.2 주문 관리

```mermaid
graph TD
    A[관리자 대시보드] --> B[주문 관리]
    B --> C[주문 목록]

    C --> D[주문 상세 보기]
    D --> E[주문 정보 확인]

    E --> F{상품 유형?}
    F -->|Digital| G[자동 발송 완료]
    F -->|Physical| H[배송 준비 상태]
    F -->|Service| I[예약 대기 상태]

    H --> J[송장 입력]
    J --> K[배송중으로 변경]

    G --> L[완료]
    K --> L
```

## 7. 감정 여정 (Emotional Journey)

```
진입 → 탐색 → 발견 → 결정 → 결제 → 완료 → 사용

😐    😊    🤩    🤔    😰    🎉    😍
호기심  흥미   "이거다!" 고민   긴장   성취   만족

디자인 포인트:
- 탐색: 시각적으로 매력적인 상품 카드
- 발견: 미리보기로 가치 확인
- 결정: 명확한 가격, 포함 내용 표시
- 결제: 빠르고 간편한 토스페이먼츠
- 완료: 즉시 다운로드 가능 안내
- 사용: 깔끔한 다운로드 센터
```

## Decision Log

- 비회원 주문 지원: 가입 장벽 최소화, 주문 후 회원 전환 유도
- Fast Track 결제: 디지털 상품은 장바구니 건너뛰기 옵션 제공
- 다운로드 제한: 무제한 대신 횟수/기간 제한으로 남용 방지
