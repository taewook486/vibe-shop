## 1. 문제 정의

### 1.1 현재 상황 (As-Is)

기존 쇼핑몰 솔루션(쇼피파이, 카페24)은:
- 코드가 숨겨져 있어서 커스터마이징이 어렵다
- 월 구독료가 비싸다
- AI로 수정하고 싶어도 접근이 불가능하다

### 1.2 목표 상황 (To-Be)

- 오픈소스 스캘레톤으로 코드가 투명하게 공개됨
- 일회성 구매로 소유권 확보
- AI(바이브코딩)로 자유롭게 커스터마이징 가능
- 라이브 코딩을 보며 학습 + 즉시 적용

### 1.3 왜 지금인가? (Why Now)

- AI 코딩 도구의 성숙 (Claude, Cursor, Copilot)
- "바이브코딩" 트렌드의 부상

### 유사 서비스 분석

### 차별화 포인트

| 항목 | 경쟁사 | 우리 | 왜 더 나은가? |
|------|--------|------|-------------|
| 코드 접근 | 비공개 | 완전 오픈 | AI로 커스터마이징 가능 |
| 가격 모델 | 월 구독 (3~10만원) | 일회성 구매 | 장기 비용 절감 |

### 킬러 질문 대응
> "네이버/카카오가 내일 똑같은 걸 만들면?"

그들은 솔루션을 판매하지, 코드를 가르치지 않는다. 우리의 가치는 "라이브 코딩 교육 + 오픈 스캘레톤"이다. 대기업은 이 영역에 들어오지 않는다.

## 2. 사용자 페르소나

### 2.1 주요 페르소나

| 항목 | 내용 |
|------|------|
| 이름/별칭 | "배우고 싶은 민수" |
| 나이/직업 | 35세 교육업 종사자 |
| 핵심 니즈 | 내 상품을 판매할 쇼핑몰이 필요하지만 개발 실력 부족 |
| 불편 포인트 | 기존 솔루션은 비싸고 원하는 대로 수정 불가 |
| 사용 상황 | 바이브랩스 라이브 시청 → 스캘레톤 다운로드 → AI로 커스터마이징 |

### 2.2 페르소나의 하루 (시나리오)

민수는 온라인 강의를 판매하고 싶다. 쇼피파이를 알아봤지만 월 3만원에 커스터마이징도 어렵다. 유튜브에서 "바이브코딩으로 쇼핑몰 만들기" 영상을 발견한다. 라이브 방송을 보며 코드를 다운로드받고, Claude 코드와 함께 로고와 색상을 바꾼다. 2시간 만에 자신만의 쇼핑몰이 완성된다. "이게 되네?"라는 성취감을 느낀다.

## 3. 사용자 스토리

### FEAT-0: 온보딩/인증
- [ ] 사용자로서, 카카오/구글 소셜 로그인을 할 수 있어야 한다. 왜냐하면 별도 가입 없이 빠르게 시작하고 싶기 때문.
- [ ] 사용자로서, 이메일 매직 링크로 로그인할 수 있어야 한다. 왜냐하면 비밀번호 기억이 어렵기 때문.
- [ ] 비회원으로서, 이메일만으로 주문할 수 있어야 한다. 왜냐하면 가입 장벽을 낮추고 싶기 때문.

### FEAT-1: 디지털 상품 판매 (MVP)
- [ ] 고객으로서, 상품 목록을 볼 수 있어야 한다. 왜냐하면 어떤 상품이 있는지 알아야 하기 때문.
- [ ] 고객으로서, 상품 상세 정보를 볼 수 있어야 한다. 왜냐하면 구매 결정을 내리려면 정보가 필요하기 때문.
- [ ] 고객으로서, 장바구니에 담고 결제할 수 있어야 한다. 왜냐하면 여러 상품을 한 번에 사고 싶기 때문.
- [ ] 고객으로서, 결제 완료 후 디지털 상품을 다운로드할 수 있어야 한다. 왜냐하면 즉시 사용하고 싶기 때문.
- [ ] 고객으로서, 마이페이지에서 구매 내역과 다운로드 링크를 볼 수 있어야 한다. 왜냐하면 나중에 다시 받고 싶을 수 있기 때문.

### FEAT-2: 관리자 기능 (MVP)
- [ ] 관리자로서, 상품을 등록/수정/삭제할 수 있어야 한다. 왜냐하면 판매 상품을 관리해야 하기 때문.
- [ ] 관리자로서, 주문 목록과 상태를 볼 수 있어야 한다. 왜냐하면 주문을 처리해야 하기 때문.
- [ ] 관리자로서, 디지털 파일을 업로드할 수 있어야 한다. 왜냐하면 다운로드 상품을 제공해야 하기 때문.

### FEAT-3: 실물 상품 배송 (Phase 2)
- [ ] 실물 상품 재고 관리
- [ ] 배송 주소 입력 및 송장 관리

### FEAT-4: 코칭 예약 (Phase 2)
- [ ] 캘린더 연동
- [ ] 예약 시스템

## 7. 해결 가설과 실험

### 7.1 가설
> 만약 라이브 코딩으로 쇼핑몰 스캘레톤을 제공하면, 바이브코딩에 관심 있는 비개발자들이 모일 것이다. 왜냐하면 코드를 배우면서 실제 사용할 수 있는 결과물을 얻을 수 있기 때문이다.

### 7.2 실험 루프

| 단계 | 내용 |
|------|------|
| 실험 | 라이브 1회차: 상품 리스트 + 상세 페이지 구현 |
| 관측 | 시청자 수, 채팅 반응, 스캘레톤 다운로드 수 |
| 학습 | 10명 이상 다운로드면 성공 |
| 다음 | 장바구니 + 결제 라이브 진행 |
